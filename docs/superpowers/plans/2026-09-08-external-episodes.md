# 独立 CFD 进程回合实施计划

用户已批准：Smarties 常驻，每回合由非 MPI 管理程序启动新的 IBAMR MPI 作业。

## 约束与接口

- 保留 CPU learner、25 维状态、Fx 系数奖励与既定近壁终止条件。
- 单机共享目录作为小消息通道；原子 rename 发布，序号防止重复动作；消息文件覆盖使用，不保存全场交换数据。
- Python 3.12 管理程序不导入 MPI，启动独立 learner 作业和 CFD 作业。每环境一个常驻代理 rank；每 CFD 作业独立拥有 MPI 生命周期。
- 正常终态先送达 learner，确认旧 CFD 作业退出后再启动下一回合。异常退出记录失败并结束训练，不伪造正常终态。
- 2 个 CFD 作业各 16 rank，上限 32；learner 8 线程。测试先使用较少 rank 验证进程轮换，再检查目标拓扑。
