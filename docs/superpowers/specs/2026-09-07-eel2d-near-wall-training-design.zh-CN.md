# eel2d 近壁独立回合训练设计

状态：独立CFD进程方案已完成短回合、目标rank拓扑和失败退出验证；尚未启动长程训练。本文件是设计规格，不是已验证经验。

## 目标和已确认条件

使用当前 CPU Smarties/IBAMR 耦合与已有六点速度观测，从头训练近壁游动策略。L 为鱼长，当前运动学使用 L=1。用户已确认：鱼体质心到目标壁面的距离 h 达到或超过 0.7L 时失败；鱼体任何部分接触壁面也失败。每回合随机初始高度，结束后恢复独立物理环境。所有源码、配置和启动脚本在本地保存。

## 当前代码检查结论

- `upstream/input2d.in` 使用 `periodic_dimension = 1,1`，现有案例没有真实壁面。
- `EelControlTask::reward` 为速度目标误差、频率偏离和平滑惩罚之和，没有推力项。
- `runSpeedTrackingEpisode` 在一次环境初始化中循环逻辑分段；`sendLastState` 后不恢复流场或几何。
- 当前本地未提交代码已有六个探针、17维状态；应保留这些工作，不能以 Git 检出的旧版覆盖。
- `IBHydrodynamicForceEvaluator::getHydrodynamicForceObject` 可读取整体水动力合力。它不提供已经分离的推进力和阻力。
- 历史运行中鱼沿负 x 游动；新任务前进单位向量取 (-1,0)，不能沿用诊断任务中的 (1,0)。

## 回合长度依据

2026-09-07 只读读取 node3 既有案例：

`/data2/mjwu/local/coupling-src/smarties-distributed-shutdown-fix-a4d0d91ad653/couplings/ibamr/runs/eel2d-20260824T143737Z-a4d0d91ad653-19731/simulation_000_00000/Eel2dStr/Eel2d_Trans_vel_struct_no_0`

按物理时间整数秒分组的平均前进速率绝对值：0–1秒为0.317436，1–2秒为0.465315，2–3秒为0.545449，3–4秒为0.588427，4–5秒为0.611075，5–6秒为0.622847，6–7秒为0.628949，9–10秒为0.634248。该案例虽在终态输出阶段退出异常，已生成的运动记录仍可用于选择初始回合尺度；它不证明近壁流场达到相同稳态。

基本周期 T0=2*pi/6.28，约1秒。按2026-09-08确认的更新方案：从静止开始，由 Agent 自第一个控制区间控制；净前进距离达到4L即成功结束；10T0仍未达到则按时间限制截断。6T0仅作为选择目标距离的参考，不再强制最短时长。失败和计算域安全边界优先。

不设置每回合长时间的固定动作预热，避免反复支付预热成本，并让策略同时学习启动和持续游动。起步段与后续段的速度、受力和奖励分别记录。

## 壁面和初始状态

- 使用下边界 y=-1.52 作为目标壁面，保持原8L×4L计算域和网格分辨率；x方向保持周期，y方向改为非周期并启用已有零速度Dirichlet条件。上边界也将成为远侧无滑移壁面，应在研究说明中明确。
- 每回合 h0/L 从 [0.25,0.60] 均匀采样。该区间为初始设计参数，不是文献最优值。保持初始姿态和相位一致以限定首轮问题。
- 环境根rank采样并广播，所有环境rank使用相同高度；不同环境使用不同随机数流。保存种子和每回合实际高度。
- 使用官方原始拉格朗日点整体平移，不改变点数、点距或鱼体形状。启动时检查实际质心与目标高度一致。
- 对每个已完成CFD步检查实际拉格朗日坐标：全局最小壁面间隙小于等于0则触壁失败；h/L>=0.7则越界失败。不得只在动作间隔末尾检查。
- 控制体必须仍包围完整鱼体且位于有效网格内；原控制体上下各0.7L，不能直接平移到近壁高度。近壁控制体需重新选取并验证，墙面通量与应力不得漏算。
- 探针在近壁和转向时可能落入固体或壁外；采样必须检查物理位置与插值支撑。不得静默读取壁外值、夹紧坐标却仍声称是原探针位置。具体有效性处理在实现前与状态定义一起确定。

## 奖励定义：用户已确认使用Fx合力

用户明确要求直接用Fx方向合力计算推力系数并奖励该系数，不进行推力/阻力分解。为保留原始物理含义，日志保留Fx，系数注明采用净水动力定义。

采用前进方向e=(-1,0)、固定参考速度Uref=L/T0、二维单位展长定义：

`CT(t) = -Fx(t)/(0.5*rho*Uref^2*L)`

`r_force = sum(CT_new * actual_dt)/nominal_control_interval`

对完整动作区间这是时间平均系数；由于触壁等原因提前结束时，仅累计已完成步，防止短区间被不恰当地放大。保留符号，不取绝对值或正部。初版reward为该项加一次失败惩罚-1，不加入速度跟踪、进度、能耗或成功奖金，以遵守用户指定目标；成功/截断规则独立于reward。可记录频率变化但不默认以其惩罚替换Fx目标。

这是用户定义的净力系数奖励，不能以训练结果声称已经分离并优化了真实推进力。必须检查系数符号、力单位、CV边界合法性及逐步累积的时间权重。

## 状态、动作和重置

- 保留当前频率比动作及限幅、变化率限制。首轮仍只控制尾摆频率，不声称能够独立操纵方向；如果它不能维持近壁游动，需据失败分布再判断是否增加转向动作。
- 使用已确认的25维观测：h/L、最小间隙/L、沿壁及法向速度、姿态sin/cos、角速度、尾摆sin/cos、当前及上次频率比、六点12个相对平移流速分量、剩余目标距离/L、剩余时间比例。固定坐标轴为负x前进、正y离开下壁面。废除目标速度观测，从新网络开始。
- 真失败用`sendTermState`；时间截断用`sendLastState`；目标到达属于任务终态。
- Smarties作业的driver、learner和代理rank在整个训练中保持存活。普通非MPI管理程序在每回合启动独立CFD MPI作业。
- 每个CFD作业只运行一个物理回合，自行初始化和结束MPI/PETSc/IBTK；不在同一进程内反复初始化库或清理全局单例。
- 终态先交给learner，旧CFD作业退出并回收后才启动替代回合。CFD启动或求解异常传播为训练失败，不等同于物理失败奖励。该方案替代未通过的同进程重建尝试。
- 每个物理回合有独立输出子目录，不能覆盖前一回合数据，也不能让VisIt步号倒退。

## 训练和输出安排

计划使用node3、两个IBAMR环境，每个16个MPI rank；learner一个rank、8个CPU线程。IBAMR合计32个rank，每rank一个计算线程。启动前依据CPU拓扑和其他任务占用选择不重叠CPU，保持learner与CFD分离。

网络从头初始化，使用CPU V-RACER。初始计划为64×64网络、batchSize=32、minTotObsNum=128、maxTotObsNum=20000、每个新观测约一次更新，checkpoint间隔256次更新；具体键以当前Smarties实现支持的语义为准。有效动作预算先定为8192，回合最多约80次动作，即无提前失败时约100余回合；失败多则回合数更多。该预算是首轮训练配置，不是已收敛保证。需在启动时说明Smarties预填充样本与动作预算的关系。

每动作保存小体量结构化记录：时间、回合、初始高度、位姿、速度、最小间隙、动作、奖励分量、失败原因；保存训练指标和定期Agent checkpoint。默认不保存每CFD步完整场、不为每回合写大型restart。保留首个完整回合和训练后独立评估的完整可视化，其余回合以标量为主。预计存储上限写入启动配置。
